# User guide

For people who submit and watch jobs through this access point — its web
interface, its chat assistant, or the REST API — and who administer
nothing.

This guide has not been written yet; it is stage 4 of the documentation
plan. Until then, the material closest to it sits in the operator guide:

- [What to hand a user](../operator/agents.md#what-to-hand-a-user) — connecting a chat client to this access point.
- [Interactive sessions and apps](../operator/interactive.md) — browser terminals, JupyterLab and VS Code.
- [The file service](../operator/ssh-gateway.md#the-file-service) — moving files in and out over SSH.
- [API surface](../developer/api.md) — what the REST endpoints cover.
