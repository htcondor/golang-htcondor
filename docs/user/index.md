# User guide

For people who submit and watch jobs through this access point — its web
interface, its chat assistant, or the REST API — and who administer
nothing.

- [Submitting and watching a job](jobs.md) — the REST API from the point of view of somebody running jobs on it.
- [Working with an AI assistant](assistant.md) — connecting one, what it may do as you, and what to watch for.
- [Interactive sessions](interactive.md) — a terminal, a notebook or VS Code on a machine in the pool.
- [Shell access over SSH](ssh.md) — getting a terminal inside a running job, and certificates for scripts.
- [Submitting over SFTP](sftp-job-submit.md) — starting a batch by dropping files, with no client to install.
- [Files and jobs over SFTP](files.md) — reading output, starting a batch from a CSV, submitting a job of your own.
- [Connecting an account](connectors.md) — letting the access point read files from your Drive, or write results to your spreadsheet.

More of this guide is still to be written. Until it is, the material
closest to it sits in the other guides:

- [API surface](../developer/api.md) — what the REST endpoints cover.
- [Interactive sessions and apps](../operator/interactive.md) — the operator's side of the page above: which applications a site offers, and the limits it sets.
